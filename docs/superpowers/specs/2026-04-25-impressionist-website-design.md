## 1. 项目概述

为视觉艺术家（画家）构建一个富有艺术气息的个人网站，直接以梵高《星月夜》和莫奈《日出·印象》原画作为设计核心元素，打造沉浸式印象派视觉体验。

**核心定位：** 综合个人主页（关于我 · 作品集 · 简历 · 联系）  
**目标受众：** 艺术爱好者、潜在合作方、画廊、媒体  
**版权说明：** 两幅画均为公共领域作品，可自由使用

## 2. 视觉风格

- **梵高风格**（《星月夜》）：旋涡深蓝星夜、燃烧金黄、强烈情感张力、表现主义笔触

## 3. 架构方案

**单页滚动画卷（Single-Page Scroll）**

- 纯 HTML + CSS + JavaScript，无框架依赖
- 单个 `index.html` 文件，配合 `style.css` 和 `script.js`
- 部署方式：GitHub Pages / Netlify / 任意静态托管，零配置
- 响应式设计：桌面优先，兼容移动端

## 4. 五个板块详细设计

### 4.1 首页（Hero）
- **背景**：《星月夜》原画全屏铺满，叠加 `rgba(10,10,30,0.15)→0.55` 渐变遮罩保证文字可读
- **内容**：
  - 小眼 eyebrow 文字：`Visual Artist`（大写字距，金色）
  - 主名字：大号衬线体，白色，文字阴影
  - 副标题：斜体，`"光影与笔触的探索者"`
  - 两个按钮：「探索作品」（金边）·「了解我」（白边幽灵）
  - 底部滚动提示：`↓ 向下滚动，展开画卷`
- **动效**：入场时名字从下方 fadeUp；星月夜背景轻微 parallax（滚动时背景移速慢于内容）

### 4.2 关于我（About）
- **布局**：左右两栏
  - 左栏：《日出·印象》原画裁切展示，右侧渐变淡入深蓝（`linear-gradient(90deg, transparent 60%, #1a1a4e 100%)`）
  - 右栏：深蓝底，头像圆形（金色边框）+ 自述文字 + 技能标签云
- **内容占位**：
  - 标题：`你好，我是 [姓名]`（金色衬线）
  - 正文：2-3 段自述，介绍创作理念、风格、经历
  - 标签：`油画` `水彩` `插画` `光影研究` 等（可自定义）
- **动效**：滚动进入视口时，左图从左 slideIn，右文从右 slideIn

### 4.3 作品集（Works）
- **背景**：《星月夜》原画全铺，叠加 `rgba(5,5,20,0.82)→0.88` 深色遮罩，营造夜间画廊氛围
- **布局**：
  - 顶部斜体标题：`— 近期创作 —`（金色，居中）
  - 4 列网格画廊，每张卡片：金色边框（`rgba(245,200,66,0.3)`）、作品缩略图、斜体标题
  - 点击卡片触发灯箱（Lightbox）放大展示，黑色遮罩背景
- **筛选**：Phase 2，初版不实现；初版仅展示全部作品网格
- **动效**：卡片悬停时金边加亮、轻微 scale(1.03)；进入视口时依次 fadeIn（stagger）

### 4.4 简历（Resume）
- **背景**：《日出·印象》原画全铺，叠加 `rgba(20,15,40,0.75)` 深色遮罩，暖橙晨光透出
- **布局**：
  - 左侧竖排标题：`履历`（金色，vertical writing-mode）
  - 右侧竖向时间轴：金色渐变竖线 + 金色节点圆点（发光效果）
  - 每个节点：年份（金色小字）+ 职位/学校（白色衬线）+ 单位/描述（半透明）
- **内容区块**：工作经历 + 教育背景，两组时间轴
- **动效**：时间轴线从上往下 drawIn（height 0→full）；节点依次 popIn

### 4.5 联系（Contact）
- **背景**：《日出·印象》原画全铺，叠加轻遮罩（`rgba(10,10,40,0.4)`），保留原画橙红晨光
- **布局**：左右两栏
  - 左：梵高名言引用（白色斜体衬线，金色左边线）+ 社交媒体图标链接（邮件 / Instagram / 微博）
  - 右：联系表单（姓名 + 邮箱 + 留言文本框 + 发送按钮），表单背景毛玻璃效果
- **动效**：表单字段 focus 时金色光晕边框；按钮悬停时金色填充

## 5. 全局交互设计

### 导航栏
- 顶部固定，毛玻璃效果（`backdrop-filter: blur(12px)`）
- 左侧：艺术家名字（金色斜体衬线）
- 右侧：五个导航链接，当前节金色高亮
- 初始透明，向下滚动超过 80px 时渐显深色背景
- 点击链接平滑滚动至对应板块（`scroll-behavior: smooth`）

### 滚动动效
- 使用 Intersection Observer API 监听各板块进入视口
- 入场动画：fadeUp（默认）· slideInLeft · slideInRight（因板块而异）
- Parallax：Hero 和 Resume 背景图移速为内容的 0.5 倍，JS scroll listener 更新 `background-position-y` 实现

### 光标
- 可选：自定义画笔形光标（cursor: url('brush.cur')），为艺术家身份加分

## 7. 技术规格

- **HTML**：语义化标签（`<header>` `<section>` `<nav>` `<footer>`）
- **CSS**：CSS 变量管理色彩系统，Flexbox + Grid 布局，无预处理器
- **JavaScript**：原生 JS，Intersection Observer（滚动动效）+ scroll listener（导航栏）+ Lightbox（作品放大）
- **图片**：原画从 Wikimedia Commons CDN 加载；作品缩略图放 `images/works/`
- **性能**：图片懒加载（`loading="lazy"`），原画图片添加 `will-change: transform` 优化 parallax
